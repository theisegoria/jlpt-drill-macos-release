# JLPT Drill for macOS

A focused daily Japanese study app for macOS 26.

## Download

Download `JLPTDrill-6.0.0-macOS-arm64.zip` from the [latest release](https://github.com/theisegoria/jlpt-drill-macos-release/releases/latest), unzip it, and move `JLPTDrill.app` to Applications.

## Requirements

- macOS 26.0 or later
- An Apple silicon Mac (the build is arm64 only), with at least 8 GB of memory
- Roughly 1.7 GB compressed, because the offline Qwen speech model ships inside the app

This release is an unsigned, non-notarized distribution build. On first launch, Control-click the app, choose **Open**, and confirm.

The source code is intentionally not included in this binary release repository.
