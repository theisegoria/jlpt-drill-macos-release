# JLPT Drill for macOS

A focused daily Japanese study app for macOS 26.

## Download

Download the latest `JLPTDrillMac-1.0.0-macos.zip` from the Releases page, unzip it, and move `JLPTDrillMac.app` to Applications.

## Requirements

- macOS 26.0 or later
- Apple Silicon or Intel Mac supported by the built target

This release is an unsigned, non-notarized distribution build. macOS may ask you to confirm opening it in Privacy & Security on first launch.

The source code is intentionally not included in this binary release repository.
